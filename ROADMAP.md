# Roadmap

The project stays intentionally small and local-first. Possible next steps are:

- Add opt-in Git history scanning with the same redacted output guarantee.
- Add checks for dependency manifests and lockfile drift.
- Add SARIF output for code scanning integrations.
- Expand tests for Windows paths, encodings, and generated repositories.

Suggestions and focused pull requests are welcome. A new check should explain its signal, avoid printing values, and include a regression test.
