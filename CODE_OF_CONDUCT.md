# Contributor Covenant Code of Conduct

## Our pledge

We want this project to be welcoming and useful to everyone. Contributors are expected to act professionally, assume good intent, and focus feedback on the work.

## Our standards

Examples of helpful behavior include clear technical discussion, respectful disagreement, and taking responsibility for mistakes. Harassment, personal attacks, discrimination, publishing private information, and other unwelcome conduct are not acceptable.

## Enforcement

Report a concern privately through the repository owner profile on GitHub. Reports will be reviewed and handled as promptly and fairly as possible. A report should include a link or description of the relevant conduct and any context needed to understand it.

This code of conduct is adapted from the Contributor Covenant, version 2.1.
